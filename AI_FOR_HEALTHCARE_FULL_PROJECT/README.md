
# AI for Healthcare – Full Project

## Overview
A complete, runnable AI healthcare web application that predicts heart disease risk using machine learning.

## Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- HTML/CSS

## How to Run
1. Install Python 3.9+
2. Open terminal in project folder
3. Install dependencies:
   pip install -r requirements.txt
4. Run the app:
   python app/app.py
5. Open browser and go to:
   http://127.0.0.1:5000

## Dataset
Sample heart disease dataset included in data folder.
